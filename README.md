# ✅ To-Do List App

A simple, clean task manager built with vanilla JavaScript — add, complete, and delete tasks with instant UI updates and no page reloads.

## 🔗 Live Demo
[View Live Site](https://bhawikamathur.github.io/ToDo-List-app/)

## ✨ Features
- Add new tasks instantly with a single click or input
- Click-to-toggle task completion styling (strikethrough when marked done)
- Delete tasks individually with a dedicated delete button
- Clean, card-based responsive UI
- Fully event-driven — the page updates instantly without any reload

## 🛠️ Tech Stack
- **HTML5** — page structure
- **CSS3** — custom styling, layout, and responsive design
- **JavaScript (Vanilla)** — DOM manipulation and event handling, no external libraries or frameworks used

## 🚀 Getting Started
Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/BhawikaMathur/ToDo-List-app.git
cd ToDo-List-app
```

Then simply open `index.html` in any web browser — no build steps or dependencies required.

## 📚 What I Learned
- DOM manipulation using `createElement`, `appendChild`, and `classList.toggle()`
- Handling user events (clicks) to update the UI in real time
- Building a fully functional interactive app without relying on any external library
